# Crime Data Cleaning Project

## Project Overview

This project demonstrates a real-world data cleaning workflow using Python, Pandas, and Jupyter Notebook.

The objective is to inspect, clean, transform, and validate a messy dataset to improve its quality and consistency.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Data Cleaning Tasks

- Initial dataset inspection
- Missing value analysis
- Duplicate detection and removal
- Invalid age detection and correction
- Date conversion and validation
- Data type inspection
- Data quality validation

## Validation

The cleaning workflow includes checks for duplicate records, invalid age values, date data types, and geographic coordinates.

## Privacy Note

Raw and processed datasets are excluded from this public repository. Dataset redistribution and privacy conditions should be verified before sharing any underlying records.

## How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Open the Jupyter Notebook.
4. Run the notebook cells in order.

```bash
pip install -r requirements.txt
```
